Quickstart Integration (cURL, JS, Python)

# Upload a file via API
curl -X POST "https://dgx-cloud.onrender.com/api/v1/upload" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "X-File-Name: photo.jpg" \
  --data-binary "@photo.jpg"

# Stream or Download a file
curl "https://dgx-cloud.onrender.com/api/v1/stream/FILE_ID?api_key=YOUR_API_KEY"

# List all files for this API key
curl "https://dgx-cloud.onrender.com/api/v1/files" \
  -H "Authorization: Bearer YOUR_API_KEY"

A note from DG Cloud
End-to-End Privacy & Data Shield

Military-Grade Cloud Security

Aapka sara data aapke personal Telegram account me safe rehta hai — Zero centralized plain-text risks.

🛡️
User's Personal Account Storage

All files are saved directly into your personal Telegram Saved Messages / Cloud. They are never kept on our servers or exposed on public disks. Even if our servers restart, your files remain 100% safe inside your Telegram.

🔒
MTProto 2.0 & AES-256 Encryption

Every single byte uploaded or streamed is encrypted end-to-end via Telegram MTProto 2.0 cryptographic channel. No hacker, middleman, or ISP can snoop or access your private photos, videos, or documents.

⚡
Zero-Knowledge Architecture

No passwords stored without cryptographic Argon/Bcrypt hashing. Private Vault files require a secondary local PIN. We never sell, scan, analyze, or train AI models on your files.

🔑
Instant Revocation & Safe Sharing

Public links use cryptographically secure 128-bit random tokens that you can disable, revoke, or delete at any time with a single click.
